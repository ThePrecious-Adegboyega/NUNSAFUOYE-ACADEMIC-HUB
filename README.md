# NUNSA FUOYE Academic Hub

The official academic resource platform for nursing students at Federal University Oye-Ekiti (FUOYE).

Built by **Precious Busola Adegboyega**, Vice President, NUNSA FUOYE Chapter 2026/27.

## Features
- Resource library organised by level and semester
- Alumni mentorship request system
- Student resource upload with review
- WhatsApp sharing on every resource card
- FAQ and About sections

## To update resources
Edit `index.html` and add new resource cards following the existing pattern.

## Deployed on
[Netlify](https://app.netlify.com)
